Clipfetch Source

Download video and audio from 1,700+ sites.

Clipfetch is a self-hosted, ad-free downloader for YouTube, TikTok, Instagram, X, Facebook, Vimeo, Reddit and anything else yt-dlp supports. Paste a link, pick MP4, MP3 or M4A, and save it — with live progress and no popups.

This page is the project home, not a hosted app. GitHub Pages can only serve static files, and Clipfetch needs a Node server plus yt-dlp and FFmpeg. Run it on your own machine or server with the one command below.

Quick start

1 Clone the repository 
git clone https://github.com/shehankanchana12-art/Downloader.git
cd Downloader
2 Build and run the container (needs Docker) 
docker compose up --build
3 Open http://localhost:4000

What you get

MP4, MP3 or M4A

Best, 1080p, 720p, 480p or 360p video; 320 or 128 kbps MP3; original-quality M4A.

Live progress

Server-Sent Events drive the progress bar from yt-dlp's real download percentage.

Nothing kept

One temp file per request in /tmp, deleted the moment the download finishes.

Built-in limits

60-minute source cap and 10 requests per minute per IP, configurable by env vars.

Safe by construction

yt-dlp runs through spawn() with argument arrays — never a shell string.

Single container

Express serves the static Next.js build and the API from one port, behind any proxy.
